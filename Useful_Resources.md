# Useful Resources


### Websites:

1. [Kaggle](https://kaggle.com) - Great for machine learning and basic python, teaches you how to build basic ML models and related concepts
2. [Exercism](https://exercism.com) - Great to learn and practice new programming languages
3. [Code Crafters](https://app.codecrafters.io)- Helps you master programming languages by building projects from easy to advanced,can also help for interview prep
4. [TryHackMe](https://tryhackme.com/) - Learn cyber security and penetration testing through playing CTFs, walkthroughs are available online to learn as well.
5. [HackTheBox](https://www.hackthebox.com/) - An alternative i use for TryHackMe,less friendly for beginners and generally harder.

### Youtube Channels:

1. [StatQuest with Josh Starmer](https://www.youtube.com/channel/UCtYLUTtgS3k1Fg4y5tAhLbw) - Teaches you machine learning and statistics in very simple and easy to understand terms,also has songs!


2. [Nick Chapsas](https://www.youtube.com/@nickchapsas) - Has great content regarding C#, teaches in depth concepts and best practices
3. [IAmTimCorey](https://www.youtube.com/@IAmTimCorey) - Has a great C# series for beginners and general developer content.
